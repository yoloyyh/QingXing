# 轻醒 · 技术与验证说明

[返回产品首页](../README.md)

本文保留实现与诊断细节；以下命令均在项目根目录执行。

一个原生 macOS 状态栏小工具：提醒离开屏幕休息、持续靠近、低头和侧倾。小猫头鹰用眼睛、头部和翅膀回应检测结果；调整后会开心跃起、冒出星星，并给出“主动调整 +1”。

## 运行

需要 macOS 14 或更新版本。当前构建适用于本机 Apple Silicon Mac。

1. 双击 `build/轻醒.app`。主控制窗口会常驻，普通输入、Tab、Esc 或切换应用不自动收起；可拖动、最小化或关闭窗口，后台提醒继续。保留顶部状态栏，并提供 Dock / Command-Tab 入口；再次双击应用或点击 Dock 可恢复窗口。
2. 可先点“试试提醒”，或到“设置 → 看看小猫头鹰的表情”选择距离、低头、侧倾、休息、奖励和没看清的表情；不启用摄像头也能体验，演示不会增加真实次数或改变工作时长。
3. 首次点击“校准 5 秒并开始”，坐稳靠好、面向镜头，再点“坐好啦，记录参考 5 秒”；此时才会在需要时请求摄像头授权并开始采集。无需测量或填写距离，打开引导页时摄像头保持关闭。
4. 靠好坐稳、自然看屏幕，让脸部清晰入镜即可，不需要双肩。每轮最多 5 秒，至少 4 个稳定样本、跨度达到 1.5 秒才记录脸宽及头部角度；默认采用 60 cm 估算距离尺度。双肩清晰时可补充记录相对头肩参考，双肩缺失不阻止头部参考成功。角度未获取时距离参考仍可使用，不延长采集。旧距离参考保留；已有可信俯仰参考可迁移用于低头判断，不猜测侧倾角度，之后主动校准时再补齐。
5. 菜单栏固定显示“小图标 + 轻醒”短标签，检测时图标变为相机、暂停时变为暂停符号。悬停或点击可看状态和倒计时；到 5 秒自动停止并释放本应用的摄像头。默认间隔 30 分钟再检测 5 秒，等待期间摄像头关闭；设置里可关闭自动检测，改为仅手动。可随时停止本轮、停止自动检测或暂停 15 分钟。

首次启动不会自动开启摄像头。完成一轮后显示“检测结束 / 等待检测”，检测结果标注“最近检测”，不表示正在持续观察。调整后可点击“调整好了，复查 5 秒”，确认恢复后获得小猫头鹰庆祝。权限被拒绝后可使用手动休息计时，并从设置页打开系统摄像头授权。视频会议时可手动开启“安静模式”；本应用不读取其他应用或系统专注模式来识别会议。

校准稳定性根据人脸在画面中的大小判断，不能直接证明人实际移动。算法最多保留 5 个有效样本，只允许过滤 1 个由前后稳定样本确认的内部跳变；仍须有 4 个样本符合原来的 12% 稳定范围，并跨越 1.5 秒。最新变化不能被当作噪声忽略，持续移动和跟踪中断仍不保存。失败说明使用“人脸大小暂不稳定”，不再直接断言距离变化。

尚未检测时，“屏幕距离”显示“等待检测”。一轮结束后保留本轮最近的有效数值并标注“最近检测”，不会因为最后一帧恰好没识别到而抹掉结果；整轮没有有效人脸时，直接显示具体原因。停止或等待下一轮不会把历史结果变成识别失败。之后每轮都和首次成功校准保存的固定参考比较；检测本身不更新参考，只有主动重新校准才更新。

根据固定参考与当前人脸尺度估算距离变化：参考距离 × 参考脸宽 ÷ 当前脸宽。±5 cm 内显示“参考范围内”，靠近超过 5 cm 并持续 3 秒才提醒；比参考更远只显示变化。调整到离参考不超过 3 cm 的靠近范围并保持 3 秒，沿用调整奖励，避免在 5 cm 边界抖动时反复发奖。

默认 60 cm 是产品选取的估算尺度，位于 [OSHA 建议的 50–100 cm](https://www.osha.gov/etools/computer-workstations/components/monitors) 和 [CCOHS 建议的 40–74 cm](https://www.ccohs.ca/oshanswers/ergonomics/office/monitor_positioning.html) 范围内，不表示已测得用户实际距离或唯一适用距离。界面标注“默认参考 / 仅估算”，设置中提供来源链接。

默认每工作 45 分钟、休息 5 分钟。在“设置 → 工作与休息”中可分别调整工作间隔（15–90 分钟，每步 5 分钟）和每次休息时长（1–20 分钟，每步 1 分钟），也可选择 25/5、45/5、50/10 快捷方案。设置会保存，原有工作间隔保持不变。HSE 建议短而频繁地离开屏幕，举例[每小时休息 5–10 分钟](https://www.hse.gov.uk/msd/dse/work-routine.htm)；45/5 是可调整的产品默认组合。

到点后休息卡片显示 30 秒后自动收起；超时 3 分钟增加暖色屏幕边框和菜单栏提示，超时 10 分钟升级为居中大卡片。每级只提示一次，边框可穿透鼠标、不获取键盘焦点，柔和变化后保持静止，并遵循系统减少动态效果设置。

点击“现在休息”立即收起提醒，并按所选分钟开始倒计时。当前休息使用开始时的目标，途中修改时长在下次休息生效。健康环以工作间隔为预算，工作时逐渐消耗；主动休息从开始时的剩余能量逐步补至 100%，表示工作与休息节奏，并非生理健康评分。到时自动完成并记录一次休息，保持“满血状态”，直到点击“满血出发”才恢复工作与后续检测；提前返回保留原来的工作累计。重复计时、重复完成和关闭庆祝卡片均不会重复计数。关闭休息提醒或点击“5 分钟后提醒”均暂缓 5 分钟，之后按当时超时程度提示。安静、暂停、锁屏、睡眠及停止工作时隐藏提醒；已开始的休息在解锁后可确认到时完成。

奖励卡片居中显示并停留 8 秒：主动调整使用大号“+1”及今日累计，休息完成使用满环、“100%”与“满血状态”。主界面的双列计数持续显示今日调整和充满次数。调整奖励不修改休息预算，演示不计入真实数据。`--check-health-ring` 可运行无摄像头的到时、提前取消、时长快照、锁屏、安静和多次调整检查。

可在设置里关闭“超时后增强休息提醒”，保留普通到点卡片。点击“预览休息提醒”可逐级体验卡片、边框和完成奖励；演示不增加真实次数、不改变工作时长，也不启动摄像头。屏幕边框只利用显示器几何放置本应用的透明窗口，不读取屏幕内容，不新增系统权限。

## 距离复查

同一轮连续三秒确认靠近超过约五厘米后，检测从半小时改为每五分钟一次，每轮仍最多五秒。下一轮仍有稳定异常证据时升级暖色大卡片，再次确认则升级居中大卡片；增强卡片常驻直到操作，每轮最多升级一次。没看清、证据中断或处于三至五厘米缓冲区时不升级、不奖励。稳定回到恢复范围三秒后，只奖励一次主动调整并恢复半小时检测。

关闭距离卡片或点击“五分钟后复查”保留纠正流程；也可主动点“调整好了，复查五秒”。暂停、休息、锁屏和睡眠暂存流程，恢复后五分钟再查，休息本身不算距离恢复。停止检测、判断不准和重新校准结束流程；关闭自动检测后仅手动复查。纠正状态只在内存中，明确退出后结束本次流程，下次登录按正常半小时规则启动。设置表情菜单可体验三级距离提醒，演示不启动摄像头、不增加真实次数。

## 猫头鹰表情

靠太近时眼睛放大、短暂出现晕圈并展开翅膀；低头时垂头并提示抬头，侧倾时只倾斜头部并提示回正；一般头肩变化使用关注表情，不冒充脖子前探诊断。休息到点时打哈欠伸翅，休息中闭眼放松，调整完成眯眼跳跃并出现星星。没有有效人脸结果时显示疑惑表情，暂停时安静闭眼。

主页与提醒卡片共享表情原因。摄像头关闭后显示“最近一次检测结果”，不继续表现正在检测；“判断不准”会收起该轮异常表情，新检测再评估。动作在状态切换时短暂播放，之后保持静态；系统启用减少动态效果时不播放。实现使用原生矢量，无新增资源下载或权限。

安静模式会屏蔽距离、姿态和休息弹窗，但保留数值结果。开启时主面板顶部显示说明及“恢复弹窗”按钮，菜单栏显示橙色静音图标（实际检测时仍优先显示相机图标），悬停可见说明。关闭安静模式会补呈现已确认且尚未恢复的距离/姿态提醒，不增加奖励；重复关闭不会重复弹窗。

## 后台运行

设置中的“登录时启动轻醒”使用 [macOS 系统登录项](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp)。启用后登录时在菜单栏后台运行，不自动打开主窗口。macOS 如要求批准，设置会显示待批准状态和系统入口；可以从 app 或系统登录项关闭。

主动开启且已有匹配参考的自动检测会被记住。下次启动在已有摄像头授权与匹配参考时恢复工作计时及三十分钟倒计时，每次仍最多五秒；不会刚登录就开摄像头、补跑错过的检测或申请新授权。停止自动检测、关闭自动开关、失去授权或参考不匹配会取消恢复意图；暂停、休息、睡眠及普通退出保留选择。关闭窗口继续后台运行，明确退出后停止本次运行，下一次登录才由系统启动。清除本地数据也会注销登录启动。

## 隐私

- 只请求摄像头权限，使用视频输入，不使用音频输入。
- 画面只在内存中分析，每轮最多 5 秒、约每秒分析两帧，不保存、不录制、不上传。
- 不读取屏幕、用户文件、剪贴板、键鼠记录、浏览记录或其他应用内容；不做人脸身份识别。
- App Sandbox 仅开放摄像头资源能力，无网络客户端能力、音频、屏幕录制或用户文件访问授权。
- 本地 UserDefaults 只保存设置、校准统计值和当天调整 / 休息次数，不保存逐帧轨迹。设置中可清除这些数据；撤销系统授权请到 macOS 隐私设置。
- 摄像头工作时系统指示灯会亮。本应用停止后，其他应用如果仍在使用摄像头，指示灯可能继续亮。

## 构建与验证

安装 Swift 6+ Command Line Tools 后，在项目目录运行；无第三方 Swift 包。肩部模型已包含在项目中，构建和运行均不下载模型：

```bash
bash scripts/test.sh
bash scripts/build-app.sh
bash scripts/verify-privacy.sh
build/轻醒.app/Contents/MacOS/QingXing --check-shoulder-model
build/轻醒.app/Contents/MacOS/QingXing --check-rest-presentation
build/轻醒.app/Contents/MacOS/QingXing --check-buddy
build/轻醒.app/Contents/MacOS/QingXing --check-background-startup
build/轻醒.app/Contents/MacOS/QingXing --check-distance-follow-up
open build/轻醒.app
```

输出为固定本机开发证书签名的 `build/轻醒.app`，尚未做 Apple 开发者证书签名和公证。证书与加密签名钥匙串保存在项目 `.signing/`（不提交、不打包），后续构建复用同一身份；无需修改系统信任设置。请保留这个目录，以免重建身份后需要重新授权。`scripts/swift-local.sh` 将编译缓存放在项目目录；对于新旧 ManifestAPI 接口混装的 Command Line Tools，只修复项目构建目录中的接口副本，不修改系统工具链。

Dock 图标使用与界面相同的小猫头鹰，包含 16–1024 像素资源。绘制源复用 `BuddyView.swift` 中的 `OwlArtwork`，图标背景在开发预览中组合。修改绘制后先导出源图，再生成 icns 并重新构建：

```bash
bash scripts/swift-local.sh build --product QingXing
.build/debug/QingXing --render-app-icon "$PWD/Resources/AppIcon-artwork.png"
swift scripts/generate-app-icon.swift
bash scripts/build-app.sh
```

`Resources/AppIcon-artwork.png` 是原生矢量导出的源图，`scripts/generate-app-icon.swift` 负责多尺寸打包，运行时没有新增图形依赖。

测试采用 Foundation 可执行程序，使用受控时间验证连续证据、误判取消、冷却、稍后提醒、恢复奖励、校准及锁屏 / 睡眠状态。这样在没有 XCTest / Swift Testing 运行库的命令行环境也可执行。

肩部的公开近景回归可运行 `bash scripts/check-shoulders-offline.sh`。首次会下载 TensorFlow 官方的两段公开测试视频及参考关键点，缓存在 `.build/pose-fixtures`，之后直接使用缓存；测试程序不打包进轻醒、不打开摄像头。它使用正式检测器对 36 个 4:3 / 16:9 上半身近景检查置信度与位置，不等同于所有用户场景的准确率验证。

开发构建可在不启用摄像头的情况下导出本应用界面，供视觉检查；此入口不包含在 release 应用中：

```bash
bash scripts/swift-local.sh build --product QingXing
.build/debug/QingXing --render-previews "$PWD/build/previews"
```

## 检测边界与实机验收

“连续使用”现在按用户开始的工作计时器累计，间歇检测期间不依赖摄像头判断是否在座；可手动暂停。新校准的厘米数根据默认 60 cm 尺度和人脸占比估算，5 cm 是估算提醒阈值，尚未验证真实测量误差能达到 5 cm。摄像头位置、画面缩放或姿态改变会影响估算；更换设备、画面规格或摆放后需重新校准。

头部姿态提醒在未设置过开关时默认开启，保留用户明确关闭的选择。低头与侧倾复用 [Apple Vision 的人脸角度](https://developer.apple.com/documentation/vision/vnfaceobservation)，无需双肩：相对自己的参考低头增加超过 15°、侧倾变化超过 12°并持续 3 秒提醒，回到低头增量 8° / 侧倾变化 6°以内并保持 3 秒奖励一次。数值为待现场验证的工程阈值，不是医学标准或颈椎角度。角度缺失时明确不能判断，不当作零或恢复。

靠后使脸变小、肩膀移出画面，但头部角度未变时，不仅凭这些变化报前倾。仅凭正面头脸无法可靠区分脖子前探和整个人前移，所以靠近仍由距离提醒单独处理。头部角度和双肩结果独立保留，最后一帧肩膀消失不抹掉先前结果。头部提醒可在无双肩时确认恢复；肩部提醒不能因为肩膀消失而获得奖励。

可选的双肩几何仍使用随包提供的 2.6 MB PoseNet（[Apple 官方示例](https://developer.apple.com/documentation/coreml/detecting-human-body-poses-in-an-image)，许可和来源见 Resources/PoseNet），以保比例补边及原图坐标还原定位。它仅补充头部相对双肩的位置、肩线及比例变化，不是头部模式的前置条件。旧肩部模型参考不混用；已有可信 pitch 可迁移为低头参考，roll 保持未知，不用默认零代替。

校准预览显示完整采集画面。头部参考只要求面向镜头、角度稳定，双肩不再决定校准是否完成。只有距离参考时，普通检测仍可使用距离，同时提供“记录距离和头部”的明确入口；只有主动进入校准页并开始记录才更新参考。

需在实际工作环境完成首次授权与摄像头校准，并验证正常阅读、转看副屏、戴眼镜、低光、整个人靠近与仅头部变化的误报和漏报。尚未完成的一小时能耗实测和多设备准确率测试不属于已验证结果。

详细交互见 `docs/superpowers/specs/2026-11-05-macos-posture-assistant-design.md`。

菜单栏入口的排序由 macOS 管理，可按住 Command 在菜单栏内拖动排序；轻醒会保存自己的排序标识。图标不按普通窗口的方式跨显示器拖动。

## 摄像头授权与提示

仅在用户主动开启、且 macOS 返回“尚未决定”时请求摄像头权限。已允许时直接复用；拒绝或撤销后停止检测，不反复弹出授权请求。定时检测不会主动申请权限。

应用自己的检测介绍只显示首次，后续仍通过顶部相机图标、倒计时和系统摄像头指示显示使用状态。构建已改用固定本地证书和应用标识。首次从临时签名切换到固定身份时，macOS 可能要求再允许一次；后续更新保留同一签名要求，避免每次重建都被识别成新应用。始终读取 macOS 当前授权状态，用户撤销后不会绕过权限。

验证更新后的代码身份：`python3 scripts/verify-signature-stability.py build/轻醒.app`。它只修改临时副本的版本号并重新签名，确认旧版本签名要求接受新版本，不打开摄像头。

## 短窗口恢复确认

连续正常 3 秒仍可立即确认恢复；自然结束的一轮检测，也允许末尾至少 4 个连续正常有效样本、跨度至少 1.5 秒时确认。未知、再次偏近、姿态证据不足会中断该段证据；取消检测或跨轮不累计、不奖励。过渡状态仅更新已有提醒，不另弹“对，就是这样”。不足以确认时保留待复查状态，界面说明本轮未完成确认。

## 弹窗显示时长

距离和休息提醒从创建起最多显示 30 秒，随后仅收起卡片，不停止检测、不重置距离复查、不确认调整成功或完成休息。奖励与普通提示继续使用原来的更短时长。重新打开主窗口不会重置同一张提醒的到期时间。

## 短窗口偏近确认

偏近提示与恢复提示一样支持自然结束时的稳定尾段：至少 4 个连续有效偏近样本、跨度至少 1.5 秒。仍保留原连续 3 秒实时触发方式；未知或正常样本中断偏近证据，不跨轮累积，取消不触发，同一轮只提醒一次。主动忽略、稍后提醒和现有优先级仍生效。

## 最近一轮提醒诊断

主界面“本轮提醒”显示偏近证据是否足够及弹窗投递结果。`qx.lastScanDecision` 只覆盖保存最近一轮的时间、样本数、有效样本数、最近相对距离估算、复查等级和决策说明，不含画面、设备标识或其他应用信息。窗口实际显示及 30 秒自动收起会更新结果；清除本地数据会删除该记录。

## 主界面检测结论

猫头鹰下方标题区分未校准、首次等待、检测中、上次距离正常或更远、偏近、姿态变化、待确认恢复、失败和暂停。小字注明距上次检测的时间、姿态判断是否可用、下次更新时间；距离正常不代表未获取的头部姿态正常。

## 外观主题

设置提供雾蓝（默认）、琥珀棕、奶咖。选择保存在 `qx.theme`；旧版本及未知值回退雾蓝。ThemePalette 按每个 AppState 的选择提供颜色，OwlArtwork 与 Dock 图标共用主题羽毛、面盘和瞳孔颜色；没有全局可变主题或额外图像下载。运行时 Dock 随选择即时切换，Finder 中应用包图标保持默认雾蓝。切换不改变校准、检测、计时、奖励或弹窗到期时间。清除本地数据会恢复默认主题。

验证：`build/轻醒.app/Contents/MacOS/QingXing --check-themes`。开发预览：`.build/debug/QingXing --render-themes build/theme-previews`。
